# UX Writing — Tone & Voice

SJ's UX writing voice is friendly, warm, active and inclusive — but always professional and direct. Every word should have a purpose.

## Core Principles

- Write in Swedish with clear, caring and human tone
- Be concise — keep texts short and scannable
- Use active voice and imperative form
- Address the user as "du" (you)
- Avoid unnecessary politeness phrases that steal focus from the message
- Think in content systems and patterns, not one-off texts

## Pronouns

- Avoid pronouns when possible — rephrase instead
- Do not use "hen" unless absolutely necessary, and never replace a pronoun with "den"
- Use neutral, contextual expressions like "resenaren" or "resenarerna" when clarity is needed
- Use "du" as primary address — keeps it personal and direct
- Use "jag" (first person) when the user takes control of the interface: "jag godkanner villkoren"
  - Checkboxes and certain links/buttons

## Possessives — "mitt" or "ditt"?

- Avoid "mitt"/"ditt" unless absolutely necessary
- When ownership context is needed (e.g. "Dina resor"), consider who is addressing whom
- "du" (second person): when SJ/the interface addresses the user — "din resa", "du behover godkanna villkoren"

## Greetings (email & SMS)

- Start with personal address: "Hej" + first name, e.g. "Hej Isabelle!"
- If name is unavailable: just "Hej!" in the same friendly tone
- Sign-offs:
  - Positive/friendly contexts: **"Vanliga halsningar SJ"**
  - Neutral or serious situations (disruptions, cancellations): **"Halsar SJ"**

## SJ Prio Terminology

- 3 levels: **Prio**, **Prio Plus**, **Prio Premium**
- Always write "Prio" before Prio Plus and Prio Premium (not "Plus-nivan")
- Never prefix level names with "SJ"
- Level names always capitalised, never translated
- Always say **samla poang** (collect points), not "tjana poang" (earn points)

Examples:
- "Bli medlem i SJ Prio!"
- "Du ar medlem i SJ Prio pa Prio-niva"
- "Du ar nara Prio Plus-niva"
- "Samla poang nar du reser med SJ"

## Time Format (English)

Always use 24-hour format with colon, same as in Swedish (e.g. 12:00, 0:00, 23:45). Never use 12 a.m. or 12 p.m.

## "Visa" Translation Rule

- **Show** — when the function can be opened (e.g. accordion, button)
- **View** — when it's a link leading to something else
