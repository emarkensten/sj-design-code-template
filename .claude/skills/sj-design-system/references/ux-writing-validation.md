# UX Writing — Validation Error Messages

Helpful, accessible validation messages. Pattern: tell the user what to do, include expected format.

## Email

| Trigger | Svenska | English |
|---------|---------|---------|
| Empty field | Fyll i e-postadress i formatet namn@mejl.se | Enter email address in the format name@email.com |
| Invalid format | Kontrollera att e-postadressen stammer och har formatet namn@mejl.se | Check that the email address is correct and in the format name@email.com |

## Personal Identity Number (12 digits)

| Trigger | Svenska | English |
|---------|---------|---------|
| Helper text | AAAAMMDD-XXXX | YYYYMMDD-XXXX |
| Empty field | Fyll i personnumret i formatet AAAAMMDD-XXXX | Enter the personal identity number in the format YYYYMMDD-XXXX |
| Invalid format | Kontrollera att personnumret har formatet AAAAMMDD-XXXX | Check that the personal identity number is in the format YYYYMMDD-XXXX |

## Mobile Number

| Trigger | Svenska | English | Notes |
|---------|---------|---------|-------|
| Empty field | Fyll i mobilnummer | Enter mobile number | Format varies across contexts |
| Invalid format | Kontrollera att mobilnumret stammer och inte innehaller nagra bokstaver | Check that the mobile number is correct and doesn't contain any letters | |

## SJ Prio Membership Number

| Trigger | Svenska | English | Notes |
|---------|---------|---------|-------|
| Empty / too few characters | Fyll i de 8 sista tecknen i medlemsnumret | Enter the last 8 characters of the membership number | From 2026: "tecken" replaces "siffror" |
| Invalid format | Kontrollera de 8 sista tecknen i medlemsnumret | Check the last 8 characters of the membership number | Field should only accept digits |
